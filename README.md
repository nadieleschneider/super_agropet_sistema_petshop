# 🐾 Super Agropet - Sistema de Gestão de Banho e Tosa

Sistema local, leve e intuitivo desenvolvido para a gestão de pet shops, com foco em agendamentos, cadastros de tutores e pets, e histórico completo de atendimentos.

## 🚀 Tecnologias Utilizadas
* **Backend:** Python (Flask)
* **Banco de Dados:** SQLite (Flask-SQLAlchemy)
* **Interface:** HTML5 + Tailwind CSS

## ⚙️ Como Executar o Projeto Localmente

1. Certifica-te de ter o Python instalado na tua máquina.
2. Instala as dependências necessárias no terminal:
   ```bash
   pip install Flask Flask-SQLAlchemy
